# Security Policy

This project talks directly to USB/SCSI hardware and can synthesize keyboard and
mouse input. Test it only on systems and windows where unintended input is safe.

Please report security issues privately to the repository owner through
GitHub's private vulnerability reporting feature when available. Do not include
device serial numbers, clipboard contents, proprietary vendor binaries,
authentication cookies, or personal logs in public issues.

Only the latest `main` branch is maintained during the experimental phase.
